# 🧾 User Registration Form

## 📌 Project Overview
This repository contains a complete **HTML5 Registration Form** styled with **CSS**. It allows new users to create an account by providing personal information, selecting education level and interests, and setting login credentials.  
The form is visually enhanced for clarity, accessibility, and ease of use.

---

## 📂 Project Structure
- **index.html** — The registration form built with semantic HTML5 elements.  
- **index.css** — The stylesheet that defines layout, colors, spacing, and responsive design.  
- **README.md** — Documentation for the project.

---

## ⚙️ Implementation Notes
### HTML Features
- **HTML5 standards:** Uses modern input types (`email`, `date`, `password`, etc.) for built-in validation.  
- **Semantic grouping:** Organized using `<fieldset>` and `<legend>` for logical structure.  
- **Accessibility:** Every `<input>` is paired with a `<label>` for better screen reader support.  
- **Required fields:** Important inputs like name, email, and password use the `required` attribute.  
- **User-friendly elements:** Dropdown menus, checkboxes, and radio buttons improve usability.  
- **Consent handling:** Includes Terms, Privacy, and Newsletter checkboxes for compliance.

---

### CSS Styling Highlights
- **Centered Layout:** The form is horizontally and vertically centered using Flexbox.  
- **Consistent Width:** Fixed form width for clean and balanced presentation.  
- **Typography:** Uses a simple sans-serif font for readability.  
- **Color Scheme:**  
  - Light gray background (`#f9f9f9`)  
  - Blue accents (`#2563eb`) for buttons and highlights  
- **Form Elements:**  
  - Rounded corners (`border-radius: 5px`)  
  - Smooth transitions on hover and focus  
  - Inputs expand to 100% width within the container  
- **Buttons:**  
  - Blue background with hover effects  
  - `transition: 0.3s` for smooth animations  
- **Responsive Design:**  
  - Scales well on smaller screens using percentage widths  
  - Optional media query support for full responsiveness
